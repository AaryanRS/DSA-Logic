# _`Real-World DSA`_

Learning Data Structures and Algorithms by understanding **real software problems**.

The goal is simple:

> **See a problem → understand what it needs → discover the right DSA → implement it → experiment with it.**

## _`How I'm Learning`_

For each problem, I try to understand:

```text
Real-world problem
        ↓
Think about the solution
        ↓
Discover the DSA
        ↓
Implement it
        ↓
Experiment
        ↓
Understand the trade-offs
```

Instead of starting with:

> "Today I'm learning a Doubly Linked List."

I start with something like:

> "How does browser history move backward and forward?"

Then I figure out why a **Doubly Linked List** makes sense.

## _`What You'll Find Here`_

Each folder/problem contains a small implementation based on a real-world software use case.

Examples:

- Browser History → Doubly Linked List
- Image Carousel → Doubly Linked List
- Undo / Redo → Stack
- Task Scheduler → Heap / Priority Queue
- Autocomplete → Trie
- LRU Cache → Hash Map + Doubly Linked List
- File Explorer → Tree
- Social Network Explorer → Graph
- Package Dependency Resolver → Graph + Topological Sort
- Route Planner → Graph + Shortest Path

## _`Main Goal`_

I don't want to memorize DSA names.
I want to reach the point where I can look at a software requirement and think:

> **"I recognize this problem, and I know what kind of DSA could fit here."**

This repository is my way of learning that intuition through small, practical examples.

## _`Tech`_

The examples are mainly written in **Python** and are kept intentionally small so I can understand the complete implementation.
More problems will be added as I learn.
